## 📐 Design System Details

### Component Styling

**Cards:**
```css
border-radius: 24px;           /* Friendly roundness */
box-shadow: 0 10px 35px rgba(124,58,237,.08);  /* Soft, warm shadow */
border: 2px solid lavender;    /* Soft boundary */
background: white;             /* Clean readability */
```

**Buttons:**
```css
border-radius: 24px;           /* Rounded, approachable */
background: deep-indigo;       /* Professional CTAs */
hover: scale up + shadow lift   /* Interactive feedback */
font-weight: 900;              /* Bold confidence */
```

**Animations:**
```css
fade-in: 0.5s;     /* Gentle appearance */
slide-up: 0.6s;    /* Content reveals */
lift-hover: 0.3s;  /* Interactive feedback */
```

### Typography

- **Headings:** Poppins 800 (modern, geometric, confident)
- **Body:** Inter 400-600 (readable, professional, dyslexia-friendly)
